## Quick Setup

Add `many_lints` to your `analysis_options.yaml`:

```yaml
plugins:
  many_lints: ^1.0.0
```

The analysis server will automatically download and resolve the plugin from [pub.dev](https://pub.dev/packages/many_lints).

Then pick a preset. **Every rule is off until you do**, so installing the plugin never
floods an existing codebase with warnings:

```yaml
# many_lints.yaml — next to your pubspec.yaml
preset: recommended
```

Restart the Dart Analysis Server and you're done.

:::caution[Seeing no warnings?]
That is expected without a preset — it is not a broken install. Add the
`many_lints.yaml` above, then restart the analysis server.
:::

There are four presets: `core` (37 near-certain-bug rules), `recommended` (98 rules —
`core` plus idiomatic Dart and Flutter practice), `opinionated` (162 rules — `recommended`
plus this package's own style preferences) and `none`. See
[Configuration](/many_lints/docs/configuration/) for what each contains and how to add or
drop individual rules.

:::note
Requires Dart 3.11+ (Flutter 3.41+)
:::
