## Quick Setup

Add `many_lints` to your `analysis_options.yaml`:

```yaml
plugins:
  many_lints: ^1.0.0
```

The analysis server will automatically download and resolve the plugin from [pub.dev](https://pub.dev/packages/many_lints).

Rules are opt-in. Choose whichever setup fits the project.

**Start from a preset** — `recommended` is the usual production default:

<Tabs syncKey="many-lints-config-file">
<TabItem label="analysis_options.yaml">

```yaml
# analysis_options.yaml
many_lints:
  preset: recommended
```

</TabItem>
<TabItem label="many_lints.yaml">

```yaml
# many_lints.yaml — next to pubspec.yaml
preset: recommended
```

</TabItem>
</Tabs>

**Select rules manually** — no preset is required:

<Tabs syncKey="many-lints-config-file">
<TabItem label="analysis_options.yaml">

```yaml
# analysis_options.yaml
many_lints:
  rules:
    avoid_equal_expressions: true
    avoid_only_rethrow: true
```

</TabItem>
<TabItem label="many_lints.yaml">

```yaml
# many_lints.yaml — next to pubspec.yaml
rules:
  avoid_equal_expressions: true
  avoid_only_rethrow: true
```

</TabItem>
</Tabs>

**Start from a preset and override it** — add omitted rules or disable included ones:

<Tabs syncKey="many-lints-config-file">
<TabItem label="analysis_options.yaml">

```yaml
# analysis_options.yaml
many_lints:
  preset: recommended
  rules:
    prefer_type_over_var: true
    avoid_only_rethrow: false
```

</TabItem>
<TabItem label="many_lints.yaml">

```yaml
# many_lints.yaml — next to pubspec.yaml
preset: recommended
rules:
  prefer_type_over_var: true
  avoid_only_rethrow: false
```

</TabItem>
</Tabs>

Restart the Dart Analysis Server and you're done.

:::caution[Seeing no warnings?]
No rule is enabled yet — it is not a broken install. Choose a preset or enable at least
one rule by name, then restart the analysis server.
:::

There are five presets: `core` (35 near-certain-bug rules), `recommended` (96 rules —
`core` plus likely defects and concrete runtime risks), `opinionated` (183 rules — `recommended`
plus this package's own style preferences), `pedantic` (240 rules — strict structure,
naming, complexity and ordering) and `none`. See
[Configuration](/many_lints/docs/configuration/) for manual selection, preset contents,
and per-rule overrides.

:::note
Requires Dart 3.11+ (Flutter 3.41+)
:::
